# **Data Mining and Data Integration in Biomedicine**

This repository contains a set of projects focused on data mining and data integration, with applications in biomedicine. These projects demonstrate techniques such as exploratory data analysis (EDA), machine learning for classification, and working with gene expression data. Below is a brief description of each project.

---

## **Projects Overview**

### 1. **Hands-on I: Data Analysis and Visualization of Heart Disease Dataset**
   - **Purpose**: This project focuses on analyzing a dataset related to heart disease, performing exploratory data analysis (EDA), and visualizing key relationships between clinical factors and heart disease prediction.
   - **Description**: The project involves loading a dataset from the UCI Heart Disease Repository, followed by data cleaning and transformation. EDA techniques are used to identify patterns in the dataset, such as correlations between clinical factors and heart disease. Visualizations like heatmaps and correlation plots are created to gain insights.

---

### 2. **Hands-on II: Clustering Gene Expression Data Across Tissues and Species**
   - **Purpose**: This project focuses on clustering gene expression data from healthy tissues across different species to determine whether tissue samples cluster together based on species or tissue type.
   - **Description**: The goal of the project is to analyze gene expression data from two sources: a mouse and rat tissue dataset and the GTEx human tissue dataset. The project applies various clustering techniques, such as K-Means and hierarchical clustering, to categorize tissues from different species based on their gene expression profiles. It also includes dimensionality reduction techniques like PCA and t-SNE for visualizing the clusters.

---

### 3. **Hands-on III: Gene Expression Data from TCGA for Cancer Type Classification**
   - **Purpose**: This project involves working with gene expression data from the Cancer Genome Atlas (TCGA) to build a machine learning model that can classify gene expression samples into different cancer types.
   - **Description**: The project retrieves TCGA data for two cancer types (LAML and KIRC) and prepares it for analysis. Feature selection is performed to identify the most important genes, and a classification model (e.g., random forest) is built to predict cancer types based on gene expression data. The dataset is split into training and testing sets for model evaluation.
